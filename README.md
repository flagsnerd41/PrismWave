## 🌊 About PrismWave

PrismWave is an independent Android music player built around a simple idea: **listening to music should feel as good as it sounds.**

It brings together music playback, discovery and library tools in a clean interface, with expressive album artwork, dynamic colors and a focus on smooth interactions.

## ✨ Features

- **Immersive player** — Full player and mini-player experiences.
- **Dynamic colors** — Accent colors inspired by album artwork.
- **Quick Picks** — Easy access to music and listening habits.
- **Music discovery** — Search, moods and quick discovery.
- **Personal library** — Liked songs, playlists and listening history.
- **Downloads** — Keep supported tracks available offline.
- **Atmospheric interface** — Dark UI with optional blur effects.
- **Fluid interactions** — Smooth transitions and thoughtful UI details.
