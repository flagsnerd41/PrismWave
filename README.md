# PrismWave 🌊

A clean YouTube Music client for Android.

Built from scratch with Kotlin + Jetpack Compose.  
No bloat, no clutter — just music.

## Features

- Smooth full player + mini player
- Dynamic accent colors from album art
- Quick picks, moods, history & speed dial
- Search + mood-based discovery
- Library (liked songs, playlists, history)
- Downloads
- Clean dark UI with optional blur
- Lightweight and fast

## Tech

- Kotlin + Jetpack Compose
- Media3 (ExoPlayer)
- NewPipeExtractor
- Coil
- Material 3
